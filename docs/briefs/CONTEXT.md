# Context for implementation (SPEC-249 estate seams)

## Stack

Bash-first kit. `bin/<sub>` is a thin shim that `exec`s `lib/<sub>/<sub>.sh` (ADR-0034). Python is stdlib-only outside `lib/stats`. Tests are `tests/test-*.sh` (each defines its own `assert`/`chk` helpers, `set -uo pipefail`), discovered by `tests/run-workflow.sh` from `.github/workflows/test.yml` (ubuntu + macos matrix). `docs/FEATURES.md` is generated by `bash lib/registry/feature-registry.sh generate` and its freshness is pinned by `tests/test-meta.sh`.

## Conventions

- Config: `lib/config/kit-config.sh` is the ONLY TOML reader. `kit_config_get` = project > operator > kit-root > default; `kit_config_get_root` = operator > kit-root > default (security-bearing keys). Operator file: `${KIT_CONFIG_OPERATOR:-${XDG_CONFIG_HOME:-$HOME/.config}/dwarves-kit}/kit.toml`. `_kit_toml_get` unquotes but does NOT expand `~`; `lib/wrap/wrap.sh` expands by hand (`target="${HOME}/${target#\~/}"`, around line 535). New path readers replicate that.
- `lib/config/module-registry.md` holds the key rows `config list|get|explain` render (line-oriented awk over markdown tables; columns `| ENV | section.key | default | [status] | module | description |`). `[consumer]` rows currently render as "inert" in `config list`. `tests/test-config-registry.sh` lints completeness and drift.
- Staging blocks: `lib/learn/staging-format.py` (`render` reads JSON on stdin with keys title/intent/approach/u/f/home/source; `parse <file>` prints JSON). A block starts at `## [<state>] <title>`.
- DEBT marker: `lib/classify/significance-classify.sh record <rid> [--files ..] [--impl-notes ..] "<desc>"` classifies and calls `gate-ledger.sh debt`. Runs live under `$(bash lib/telemetry/kit-log-dir.sh)/runs/<rid>.log`, one `| DEBT |` line per record.
- Precedent: `bin/precedent find --surface inventory --quiet "<words>"` prints hits then one summary line.
- Command docs: `commands/<verb>.md`, numbered steps, a step that reads an empty key prints one "skipped" line and continues (Step -1 in `commands/wrap.md`). The report grammar (Step 8) already reserves the space after `FYI` for overlay sections.
- Proof of done: `docs/verification/<slug>.md` with `## Green run`, uppercase `PASS`, the exact command, a negative control, reproduce steps.
- `tests/test-no-personal-paths.sh` rejects operator paths in docs; write `~/workspace/<owner>/...` or nothing.
- No em dashes anywhere.

## Pitfalls to design around

- `tests/test-meta.sh` is 3079 lines and scans command docs; check `grep -rn "Step 7\|Step 8" tests/` before renumbering wrap steps.
- CI checkout is depth 1: no `git show <old-ref>` in tests.
- `git status` contends for `index.lock` on ubuntu; poll the lock file instead (wrap.sh already does).
- GNU `stat -f` is filesystem mode; use `stat -c` first then `stat -f`.
